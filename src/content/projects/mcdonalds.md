## 从一份菜单，开始理解交互。

基于 Vue 的 McDonald’s 在线点餐课程项目，练习将日常业务转化为页面与组件。

### 这次练习的意义

把视觉呈现、页面结构与用户操作连接起来，在实际项目里理解前端开发的完整过程。

项目代码可在 GitHub 查看。封面为主题概念拼贴，品牌名称仅用于说明课程项目主题。
